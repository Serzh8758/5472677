# Краткое описание
Эта программа — удобный помощник для случайной генерации задач. Она позволяет выбрать или добавить задачи разных категорий (учёба, спорт, работа), случайным образом генерировать их для выполнения, а также сохранять и просматривать историю выполненных задач. Используется для организации времени, мотивации и повышения продуктивности, делая планирование проще и приятнее.
